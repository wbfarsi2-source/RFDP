# تغییرات GameBot Platform v0.7.0 Final

## رابط و روند خرید

- بازنویسی متن‌های فارسی با لحن ساده و حرفه‌ای
- حذف دریافت Cookie قبل از پرداخت
- ترتیب جدید: انتخاب سرویس، پرداخت، بررسی شبکه، تأیید ادمین، دریافت Cookie، اجرای CMD
- افزودن راهنمای دقیق استخراج Cookie از مرورگر
- حذف فوری پیام حاوی Cookie از گفت‌وگو
- ذخیره Cookie به‌صورت رمزگذاری‌شده و عدم نمایش آن در پنل ادمین
- افزودن پیام روشن برای زمان اعتبار و وضعیت Runtime بعد از فعال‌سازی

## پلن‌های Kintara

- ماهیگیری: 1 USDC
- ماهیگیری و پخت‌وپز: 1.99 USDC
- ماهیگیری، پخت‌وپز و گردونه: 2.99 USDC
- امکان تغییر قیمت، مدت و حالت رایگان یا پولی از پنل ادمین
- حذف و مخفی‌سازی کامل Merchant
- آماده‌سازی مرز مستقل گردونه؛ نمایش آن تا تعریف Endpoint معتبر غیرفعال است

## موقعیت مولتن

- انتقال کامل موقعیت مولتن به زیرمنوی Kintara
- حذف دکمه آن از صفحه اصلی
- حذف عبارت‌های «رایگان» و «پولی» از رابط کاربر
- بروزرسانی دستی و تازه داخل ربات
- نمایش فقط سه سرور برتر و تعداد بازیکنان
- حذف تاریخ، تعداد سرورهای بررسی‌شده و اطلاعات اضافی
- انتشار یک پیام ثابت در کانال و ویرایش آن هر ۶۰ ثانیه
- لینک اختصاصی، یک‌بارمصرف و زمان‌دار برای هر کاربر
- قطع دسترسی ربات و کانال پس از پایان اشتراک
- Ban و Unban فوری برای حفظ امکان بازگشت بعد از تمدید
- لغو دسترسی‌های قبلی هنگام تغییر سرویس از رایگان به پولی
- استفاده پیش‌فرض از `KINTARA_COOKIE` فایل `.env` برای Runtime مشترک

## Runtime و معماری

- یک پوشه و CMD مستقل برای هر حساب پولی یا تستی
- اجرای خودکار CMD پس از تکمیل اتصال حساب
- Restart خودکار در صورت بسته‌شدن یا Crash شدن CMD
- توقف دائمی فقط از طریق ربات، ادمین، پایان اشتراک یا غیرفعال‌شدن بازی
- تفکیک Kintara به API، خرید، تلگرام، مولتن، موتور و Runtime
- تفکیک هسته به پیکربندی، پرداخت، Runtime حساب، سرویس مشترک، اعلان و بکاپ
- حفظ Wrapperهای سازگار برای مسیرهای قدیمی
- مهاجرت خودکار Workspaceهای نسخه‌های قبلی

## مدیریت و راه‌اندازی

- تکمیل `.env.example` با تمام Placeholderهای لازم
- تنظیم کانال خصوصی Kintara
- کنترل رایگان یا پولی‌بودن سرویس‌ها از `/admin`
- کنترل والت‌ها، شبکه‌ها، قیمت‌ها، مدت‌ها، Workerها و سفارش‌ها
- تشخیص Proxy ویندوز و استفاده خودکار از آن
- کش وابستگی‌ها و حذف نصب تکراری در هر اجرا
- انگلیسی‌بودن کامل کد و نگهداری متن فارسی در فایل Locale
