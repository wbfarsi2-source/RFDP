# GameBot Platform Python v0.7.0 Final

این نسخه، بیس اصلی ربات را به هسته مستقل و ماژول‌های جدا برای هر بازی تقسیم می‌کند. مسیر خرید، پرداخت، تأیید ادمین، دریافت اطلاعات اتصال و اجرای حساب نیز برای Kintara یکپارچه شده است.

## نصب یا بروزرسانی

قبل از جایگزینی نسخه جدید، از این موارد بکاپ بگیر:

```text
C:\Users\JavadTM\Desktop\Start\.env
C:\Users\JavadTM\Desktop\Start\data\gamebot.db
C:\Users\JavadTM\Desktop\Start\games\kintara\runtime
```

محتوای ZIP را داخل این مسیر Extract و Replace کن:

```text
C:\Users\JavadTM\Desktop\Start
```

فایل `.env`، دیتابیس و پوشه Runtime را حذف نکن. سپس اجرا کن:

```text
START_GAMEBOT.bat
```

لانچر فقط زمانی وابستگی‌ها را نصب می‌کند که محیط مجازی ناقص باشد یا فایل `requirements.txt` تغییر کرده باشد. در اجراهای بعدی نصب تکراری انجام نمی‌شود.

## تنظیم اولیه

فایل زیر را کپی کن:

```text
.env.example → .env
```

سپس مقادیر توکن، آیدی ادمین، کلید رمزگذاری، والت‌ها، Cookie مشترک Kintara و تنظیمات کانال را جایگزین کن.

برای ساخت `MASTER_KEY` تازه:

```powershell
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## روند خرید سرویس Kintara

روند نهایی به این ترتیب است:

1. کاربر سرویس را انتخاب می‌کند
2. مبلغ USDC و آدرس والت نمایش داده می‌شود
3. کاربر پرداخت می‌کند و هش تراکنش را می‌فرستد
4. تراکنش در شبکه بررسی می‌شود
5. سفارش برای تأیید نهایی ادمین ارسال می‌شود
6. فقط پس از تأیید ادمین، راهنمای اتصال حساب نمایش داده می‌شود
7. پیام حاوی Cookie بلافاصله از چت حذف می‌شود
8. Cookie اعتبارسنجی و با AES-256-GCM رمزگذاری می‌شود
9. پوشه و CMD اختصاصی حساب ساخته و اجرا می‌شود
10. Supervisor تا پایان اشتراک از Process نگهداری می‌کند

قیمت‌های پیش‌فرض:

```text
ماهیگیری                         1.00 USDC
ماهیگیری و پخت‌وپز             1.99 USDC
ماهیگیری، پخت‌وپز و گردونه     2.99 USDC
```

قیمت، مدت، فعال‌بودن و حالت رایگان یا پولی هر سرویس از `/admin` قابل تغییر است.

> ماژول گردونه و قیمت آن در ساختار آماده است، اما تا زمانی که Endpoint معتبر آن در موتور Kintara تعریف نشود، در منوی کاربران مخفی می‌ماند. این کار مانع فروش قابلیتی می‌شود که هنوز اجرای آن تأیید نشده است.

Merchant کاملاً غیرفعال و مخفی است.

## موقعیت مولتن

موقعیت مولتن داخل منوی بازی Kintara قرار دارد و در صفحه اصلی ربات نمایش داده نمی‌شود.

- داخل ربات، نتیجه فقط با زدن «بروزرسانی وضعیت» دریافت می‌شود
- درخواست بروزرسانی منتظر Snapshot تازه و معتبر می‌ماند
- داخل کانال خصوصی، یک پیام ثابت هر ۶۰ ثانیه ویرایش می‌شود
- پیام فقط سه سرور برتر و تعداد بازیکنان را نشان می‌دهد
- لینک ورود هر کاربر اختصاصی، یک‌بارمصرف و زمان‌دار است
- پایان دسترسی، عضویت کانال و دسترسی ربات را قطع می‌کند
- کاربر Ban دائمی نمی‌شود و پس از تمدید می‌تواند دوباره وارد کانال شود
- تغییر حالت سرویس از رایگان به پولی، دسترسی‌های رایگان قبلی را لغو می‌کند

سرویس مشترک مولتن از این مقدار در `.env` استفاده می‌کند:

```env
KINTARA_COOKIE=__Host-kintara_session=YOUR_PROJECT_COOKIE
```

Cookie مشترک هرگز برای حساب‌های پولی کاربران استفاده نمی‌شود.

## مسیر Runtimeها

Runtime مشترک مولتن:

```text
games\kintara\runtime\shared\ember
```

Runtime هر حساب پولی یا تستی:

```text
games\kintara\runtime\users\account_<ACCOUNT_ID>
```

هر حساب فقط یک Workspace، یک `instance.json`، یک Log و یک CMD مدیریت‌شده دارد.

## رفتار Supervisor

- بستن دستی CMD حساب، Crash محسوب می‌شود و Process دوباره اجرا می‌شود
- توقف از داخل ربات یا پنل ادمین، وضعیت مطلوب را روی `stopped` قرار می‌دهد و Restart انجام نمی‌شود
- پایان اشتراک، Process را متوقف می‌کند
- پس از Restart بات اصلی، Runtimeهای فعال دوباره بازیابی می‌شوند
- محدودیت Restart و Heartbeat از `.env` یا `/admin` قابل تنظیم است

## پنل مدیریت

```text
/admin
```

از پنل می‌توان بازی‌ها، سرویس‌ها، قیمت‌ها، مدت‌ها، رایگان یا پولی‌بودن، والت‌ها، شبکه‌ها، سفارش‌ها، کاربران، Workerها، مولتن، کانال، تست، پشتیبانی، حالت تعمیر و بکاپ را مدیریت کرد.

## زبان کد

تمام فایل‌های Python، نام متغیرها، کامنت‌ها و Logهای داخلی انگلیسی هستند. متن فارسی رابط در فایل زیر نگهداری می‌شود:

```text
locales\fa_literals.json
```

جزئیات ساختار در `ARCHITECTURE_FA.md` و تغییرات نسخه در `CHANGELOG_FA.md` آمده است.
