ELDORIA MULTI-ACCOUNT CENTER - AUTO START + SETTINGS

Main menu:
  1) Start All Enabled Accounts
  2) Add New Account
  3) Settings

Behavior:
- Start has NO account-selection prompt.
- Every enabled + ready account starts automatically in its own CMD window.
- New accounts are Enabled by default.
- Settings lets you toggle each account Enabled/Disabled by number.
- Existing accounts created by older versions are treated as Enabled by default.
- Disabling an already-running account prevents future automatic starts but does not force-kill the currently running CMD. Close that account CMD to stop it immediately.
- Each account keeps isolated credentials, State, Logs, Output and instance lock.
